# 네온 블레이드

비 오는 네온 도시를 검 한 자루로 뚫고 나가는 3인칭 3D 사이버펑크 액션 게임입니다. (Vite + three.js)

박사가 경비대원 카이의 검술을 복제하다 태어난 AI 〈아담〉이 도시의 로봇을 손에 넣고 반란을 일으켰습니다. 몸의 절반을 기계로 개조당해 깨어난 카이가 박사의 무전을 따라 거리 13구역과 타워 5개 층을 돌파하고, 자신과 똑같은 모습의 아담과 맞섭니다.

- **무한 모드**: 지하철 광장에서 끝없이 몰려오는 웨이브를 버팁니다. 5웨이브마다 보스가 나오고, 웨이브가 오를수록 적과 보스가 강해집니다. 일반 적 1점, 보스 60점. 끝나면 이름을 남겨 랭킹(이 브라우저에 저장, 상위 20명)에 기록하고, 시작 화면의 〈랭킹〉에서 볼 수 있습니다
- **스토리 모드**: 중간보스 5종(골리앗, 쌍둥이 집행자, 아르고스, 헤카톤, 헬릭스)과 최종전 보스 러시. 저장 / 불러오기 3칸
- 기계 부품으로 박사에게 스탯을 올리는 강화 상점 (체력·공격력·방어·공격 속도·공격 범위 등, 같은 스탯을 여러 번 올릴 수 있음)
- 설정에서 비 효과와 빗소리를 끌 수 있습니다

## 조작
| | PC | 모바일 |
|---|---|---|
| 이동 | WASD | 왼쪽 화면 터치 |
| 시점 | 마우스 | 오른쪽 화면 드래그 |
| 공격 | 좌클릭 / J (꾹 누르면 차지) | 공격 버튼 |
| 대시 | Space | 대시 버튼 |
| 박사 호출 · 스탯 강화(전투 후) | C | 오른쪽 버튼 |
| 배낭 / 설정 | Tab 또는 오른쪽 위 배낭 버튼 | 배낭 버튼 |

## 실행
```
npm install
npm run dev      # 개발 서버
npm run build    # dist/ 로 빌드
```

`main` 브랜치에 올리면 GitHub Pages로 자동 배포됩니다. (`.github/workflows/deploy.yml`)
